# Design research synthesis

The redesign applies the common principles across the requested frontend/design skill sets: infer a strong visual brief before coding; reject generic template defaults; keep a small number of deliberate visual gestures; treat typography/spacing as primary design material; animate with purpose and reversible state; keep commerce controls accessible and obvious; measure Core Web Vitals instead of decorating around performance problems; and use Server Components / bounded client islands to avoid unnecessary React cost.

Rather than copying one perfume website, the build uses category-specific patterns: full-bleed campaign opening, editorial product staging, material/note storytelling, sample-first conversion, per-ml size economics, clear performance/drydown information and a restrained sticky buy surface.
