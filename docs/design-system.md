# Design system

Public UI is intentionally not a component-library demo. Reusable primitives are behavioural: buttons, quantity control, filters, product card, fulfillment status, form fields. Their styling follows the editorial system in `app/globals.css`.

Typography: Cormorant Garamond display + Inter utility/body through `next/font`; two families only. Display leading stays tight; body copy stays readable. Prices/quantities should use tabular figures where comparisons matter.

Commerce controls prefer 44–50px hit areas. Focus is visible and independent of hover. Accent colours are fragrance identity; action controls remain ink/cream.
